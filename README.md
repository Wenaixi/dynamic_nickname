# MaiBot 动态群名片与群氛围管理插件 (dynamic_nickname)

根据群聊活跃度、日常人设及群氛围，让麦麦自动、智能地更新自身在各个 QQ 群内的群名片（群昵称），增加趣味性与陪伴感。

## 核心特性

- 氛围与情绪映射：结合麦麦当前的人设状态、时间段及群聊主题，动态衍生出可爱生动的群昵称后置标识。
- 白名单与免扰群控制：支持配置禁止修改群名片的群号列表，防止在严肃管理群误改昵称。
- 智能冷却保护：严格控制群名片修改频率，防止高频修改触发腾讯风控。
- MaiBot 1.2.5 契约适配：已完全重构 `task_name` 调用传参，杜绝模型匹配异常。

## 配置项详解

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `[plugin].enabled` | bool | `true` | 是否启用动态群名片功能 |
| `[nickname].update_interval_hours` | int | `4` | 名片自动轮换时间间隔（小时） |
| `[nickname].base_name` | string | `"麦麦"` | 机器人基础名称前缀 |
| `[nickname].whitelist_groups` | array | `[]` | 允许动态修改名片的群号白名单 |
| `[nickname].blacklist_groups` | array | `[]` | 严禁修改名片的群号黑名单 |
